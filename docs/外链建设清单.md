> 用法：完成一项打勾一项，遇到问题在「备注」记录。

> ## ⚠️ 2026-09-22 重要认知纠正（推翻了本文档原有结论）
>
> 本文档此前写「GitHub awesome-list PR 合并 = **永久 dofollow** 外链」—— **这是错的。**
>
> **实测证据**（GitHub 自己的 Markdown 渲染接口）：
> ```
> $ gh api --method POST /markdown -f text='[x](https://indiemaker.cn/)' -f mode=gfm
> <p><a href="https://indiemaker.cn/" rel="nofollow">x</a></p>
> ```
> → GitHub 对所有用户内容里的外链统一加 `rel="nofollow"`。
>
> **所以 GitHub 侧外链的真实价值只有三块，且都不含 SEO 权重：**
> | ✅ 有 | ❌ 没有 |
> |---|---|
> | 被爬虫**发现**（多一条通往本站的 URL） | 不传递 PageRank / 链接权重 |
> | 真实 **referral 流量**（有人真的在逛这些列表） | 不提升域名权威度 |
> | 被 **AI 搜索引擎引用**（LLM 读 README，不看 nofollow） | |
>
> **结论：GitHub PR 值得做，但它是「发现渠道」，不是「权重来源」。**
> 要拿 dofollow 权重，必须走非 GitHub 平台 —— 见文末「附二」。
