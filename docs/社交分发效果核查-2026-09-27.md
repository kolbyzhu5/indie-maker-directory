## 二、Reddit 侧：三条独立证据同时指向「不可见」

### 2.1 决定性证据 —— author 搜索法 + 对照账号

shadowban 的**定义性特征**是：该账号的帖子与评论**从搜索中全部消失**。
同一查询方法、同一时刻、跑两组：

| 组 | 命令 | 结果 |
|---|---|---|
| 实验组 | `search.rss?q=author:Ok-Hotel7596` | **0 条** |
| 对照组 | `search.rss?q=author:aeshieru` | **25 条** |

> 对照组 `u/aeshieru` 是从 r/SideProject 最新流里**自动取的当天真实发帖者**（不是凭记忆挑的）。
> 同方法下对照组有 25 条、实验组 0 条 → **该账号对搜索完全不可见**。

**为什么这条比「档案 404」可靠**：档案 404 有实测假阳性（曾出现过「档案 404 但帖子健在」的账号），
而「搜索里一条都没有」几乎无法用别的原因解释。这条判据是本轮首次确立的（已写进技能）。

### 2.2 辅助证据 —— 档案端点仍 404

```
GET https://www.reddit.com/user/Ok-Hotel7596/.rss   → HTTP 404  page not found
```

⚠️ 上轮已实测过：**删除标记只能证明「没被删」，不能证明「可见」**。
本轮跑 `comments/1wpsid5.rss` 时，title 已不再是 `[ Removed by Reddit ]`
（上轮是），但账号依旧搜不到 —— 说明**「帖被撤下站级删除标记」不等于「账号已恢复」**。

### 2.3 版块公开流里也没有

```
GET https://www.reddit.com/r/SideProject/new/.rss
→ 25 帖，区间 2026-09-27 13:45 ~ 14:53 UTC（北京 21:45 ~ 22:53，覆盖 68.3 分钟）
→ 与 indiemaker / chinese indie / Ok-Hotel 相关：0 条
```

**注意这条的适用边界**：r/SideProject 近 25 帖只覆盖 **68 分钟**。
如果你的帖发得比 21:45 更早，它已经**被新帖冲走**，这条证据就不成立 ——
此时应以 2.1 的 author 搜索为准（那条不受时间窗限制）。

### 2.4 全局搜索里只有「别家」

搜 `indiemaker` 返回 25 条，全部是另一个东西（`IndieMakersTR`、`Indie Makers: resources, feedback...`
等），**没有一条是我们的站点**。

## 五、X 侧：外部核查是盲区，需要账号

**为什么查不了**：X 的公开推文没有免登录的检索端点（nitter 类镜像基本全挂），
WebSearch 也搜不到（只有已知的 w2solo 那篇）。

**我需要其中任一个**：

- **账号 handle**（如 `@xxx`）→ 我可以查该账号的公开可见性、发文节奏、是否被限制
- **推文链接** → 直接定论

**顺带提醒上轮已核实的两个事实**（与这次的「同步」是否用了我给的方案有关）：

1. **X 新号的信任分要 6–12 个月**才拿满探索配额 → **这条推文大概率不会有量**，
   别把「今天没来人」当成失败。
2. **分享链接里带 `via=YouTube&related=...` 的，等于帮 YouTube 干活**：
   曝光记在 YouTube 账上，且发布后 X 会弹窗推荐关注 YouTube 官方账号。
   上轮已在 `docs/X发布包与文案-2026-09-27.md` 给出修正后的分享按钮（现算 URL，不带脏参数）。

## 六、本轮的判定口径（写进技能，可复用）

| 想验什么 | 用什么 | 不能用什么 |
|---|---|---|
| 帖是否**被删** | `comments/<id>.rss` 的 `<title>` 删除标记 | HTTP 状态码 |
| 帖是否**可见** | `search.rss?q=author:<user>` + 对照账号 | 删除标记（它只证明没被删） |
| 账号是否**被封** | 同上（author 搜索法） | 档案 404（有假阳性） |
| 刚发的帖**在不在版里** | `r/<sub>/new/.rss` 扫关键词 + 看时间区间 | 版块订户数 |
| 分发**有没有效果** | 站点 referral ≠ 0 | 自己的发帖记录 |

**一条命令跑完全部**：

```bash
python3 ~/.workbuddy/skills/platform-post-survival-check/scripts/check.py author <账号名>
python3 ~/.workbuddy/skills/platform-post-survival-check/scripts/check.py visible SideProject --keywords indiemaker
```
