## 2026-10-02 · 工程轮：周报归档体系（/weekly/）

**起因**：用户提议在首页加「每日 GitHub 热点 / AI 圈在吵什么」板块提日活。

### 判断：方向对，位置错

| 判据 | 实测 | 结论 |

| 已编入 Google | 1,801/3,100 = 59% | 边际收益已耗尽 |

**否决「照抄全网 GitHub 热榜」**：几千个站在做同一件事 → 同质化 + 「大规模机械生成薄内容」风险，对目录站尤其危险。改用本站独有数据（2,958+ 项目 / 存活状态 / 城市 / 分类）。

   → 所以**不新建页面**，而是补它缺的那一环：**归档**（URL 固定 → 内容每周被覆盖 → 积累不下资产）。

## 10/3 深夜 · 两处可见排版缺陷修复（一处用户报 + 一处自查）

### ① 英文首页分类 chip 计数被邻项盖住（用户报）

**现象**：`/en/` 的 Browse by category 里计数显示不全 —— `AI Tools` 的 **934 显示成 93**、`Dev Tools` 的 565 显示成 56…… 但**每行最后一个 chip 完整**；且每个 chip 左侧多一个圆点。

**根因**（`scripts/en-pages.mjs` 生成的结构，三重错）：
1. `<div class="category-nav">` 里直接放 `<li>`，**无 `<ul>`/`<ol>` 父元素**（无效 HTML）
2. `<li>` 是 flex item（`flex: 0 1 auto`）**会被收缩**；而 `<small>数字</small>` 在 `<a>` **之外**、`<li>` **之内** → li 一旦被压到内容宽度以下，数字就溢出到右侧相邻 chip 底下被覆盖
3. `<li>` 默认 `list-style: disc`，`::marker` 泄漏成左侧圆点

**修法**（对齐中文版/分类页既有结构）：
- `en-pages.mjs`：改成 `<a href=…><span class="best-name" style="border:0">名称</span> <small>数字</small></a>` —— `<a>` 直接做 flex item，数字进 chip 框内
- `detail.css` 的 `.category-nav a` 加 **`white-space: nowrap; flex: 0 0 auto;`** —— 正面防御：nowrap 让 min-content = max-content，flex 收缩再也压不到内容宽度以下，放不下时换行而非压缩

**⭐ 可复用检测法（这次是靠"量"定位的，不是靠看）**：
- `el.scrollWidth - el.clientWidth > 0` → 内容溢出容器（`overflow: visible` 时**不报错、不裁切，只是静默盖住邻居**）
- 相邻 flex item 的 `boundingBox` 间距 `< gap` → 发生了压盖
- **关键推断线索：「只有每行最后一个完整」→ 说明是"被下一个元素覆盖"，而不是"容器裁切"**（裁切的话每行最后一个也会被裁）。这条线索直接把方向从"宽度不够"扭到"溢出被盖"。

**⭐ 全站复查法（防同类漏网）**：扫「非列表容器（div/section/nav/main）直接包 `<li>` 且中间没有 `<ul>/<ol>`」→ 修复后命中 **0**。

**验证**：Playwright 实测 1440/1280/1080/900/600/390 六个宽度 → marker 泄漏 0、相邻重叠 0、chip 内部溢出 0、计数右边界稳定落在框内 15px（= padding-right 14 + border 1）、chip 恒单行等高、行数随宽度 3→4→7 正常换行。中文分类页 `/c/ai-tools.html` @390px 零副作用（13 chip、无内部溢出、无横向滚动）。

### ② 中文首页品牌印章被 i18n 覆盖致溢出（自查，上一轮发现、本轮一并修）

**现象**：首页第一屏品牌位（红底书法体印章）文字溢出 50×50 方块、上下被裁，方块里是「AI 独立制造所」而不是「独立」。**英文版正常。**

**根因**：`index.html` 里两个元素**共用同一个 i18n key**：
```html
<span class="brand-seal" data-i18n="brandTitle">独立</span>
<strong data-i18n="brandTitle">AI 独立制造所</strong>
```
`i18n.js` 的 `brandTitle` 中文值是「AI 独立制造所」→ 印章也被替换成 6 字全称；`.brand-seal` 固定 `50×50` 且无 overflow 控制 → 必然溢出。**英文版幸免是因为 `en/*.html` 是构建生成的静态页，不跑运行时 i18n。**

**修法**：删掉印章上的 `data-i18n`（印章是**图形标识**，中英文都固定「独立」）。全仓核对：23 个含 `.brand-seal` 的文件里**只有这一处**多绑了 i18n。

**⭐ 判据（可复用）**：**同一个 i18n key 绑到语义不同的两个元素 = 定时炸弹**。图形标识/图标/Logo 绝不该挂 i18n。查法：`grep -c 'data-i18n="<key>"'` 在所有模板里数出现次数，>1 就要逐个看语义是否同源。

**验证**：印章文本=「独立」、无 i18n 属性、`scrollHeight=clientHeight=50`（零裁切）、`isElementClipped=false`、页面无横向溢出；**切到英文语言后印章仍为「独立」**；相邻 `<strong>` 仍正常显示「AI 独立制造所」。
