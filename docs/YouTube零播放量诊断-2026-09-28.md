## 三、根因（四层，按决定性排序）

### 第 1 层 · 硬规则：横屏 = 永远不是 Shorts ← 决定性

YouTube 官方规则（[answer/15424877](https://support.google.com/youtube/answer/15424877)）：

> Any videos uploaded on or after this date with a **square or vertical aspect ratio** up to three minutes in length will be categorized as Shorts.

- 分类发生在**处理阶段**，由视频自身的**画幅与时长**决定，**不看标签**（`#Shorts` 标题标签是远古传说，无用）。
- **16:9 横屏永远不是 Shorts**，无论多短。30 秒的横屏片段，依然是普通长视频。
- **反过来说**：76 秒的竖屏视频**自动就是 Shorts** —— 不需要剪到 60 秒。

> 记录一个常见过时认知：Shorts 上限是 **3 分钟**（2024-10-15 起从 60 秒上调），不是 60 秒。

**这一层直接决定了这个视频拿不到任何算法分发通道。**

### 第 2 层 · 算法：长视频池对新号几乎零推荐

Shorts 流是"赛马"制——没有粉丝也会被推给小批量用户测试。长视频推荐则依赖观看历史信号，新号没有信号，YouTube 给的初始测试曝光通常只有个位数到几十次。

### 第 3 层 · 导流：外部入口全部为 0

| 渠道 | 状态 |
|---|---|
| Reddit | 首帖被**站级删除**，账号 `u/Ok-Hotel7596` 疑似 shadowban（author 搜索 0 条） |
| X | 发出的链接带 YouTube 官方 `via/related` 参数，曝光记在 YouTube 账上；账号无粉丝 |
| Product Hunt | **还未发布** |

→ 没有一条外部管道往这个视频里送过人。

### 第 4 层 · 计数口径：现在的"播放量"就是"播放启动次数"

**2026-08-24 起规则变更**：`viewCount` 从**播放开始的第一帧**就计，长视频 / 直播 / Shorts 一致，**不再有 30 秒门槛**。旧的 30 秒门槛改名成 **"engaged views"**（只在 Studio Analytics 里可见）。

→ 所以 **3 views = 55 小时里只有 3 次播放启动**。这几乎就是"曝光量"的直接读数。**曝光确实是 0。**

## 五、已交付的解决方案

**竖版 Shorts 版已做好**（本轮产出）：

```
output/ph-launch/yt-promo/shorts/
├── shorts-EN-1080x1920-76s.mp4   ← 成品（1080×1920 / 76.3s / 14.4 MB / SAR 1:1）
└── subs-big.ass                  ← 大字幕源文件（14 张大字卡，可改文案重出）
```

**处理方式**：
- 1920×1080 横屏 → **1080×1920 竖版**（`crop=1640:950:140:0` 去掉原底部字幕条与左右留白 → 放大 1.19 倍提升可读性）
- 模糊背景填充上下留白（`gblur=sigma=45` + 压暗）
- **原 40 条碎字幕归并为 14 张大字卡**（每条 3–6 秒），字号 74 + 黑描边，避开 Shorts 底部 250px 的 UI 遮挡区
- 像素比已修正为 **`SAR 1:1 DAR 9:16`**（首版误产出 `SAR 9216:9215` 非标准比例，会导致分类异常）

**验收**：`Duration 00:01:16.30` · `1080x1920 [SAR 1:1 DAR 9:16]` · 抽帧确认字幕渲染正常、站点内容与报告页数字（2,973 / 85.2% / 13.6% / 1,105）清晰可辨。

### 为什么 76 秒不剪短

Shorts 上限 3 分钟且**靠画幅自动分类**，剪短没有收益，反而丢掉叙事。**唯一必要条件是把画幅改成竖屏。**

## 八、给下一次的判断原则（别再误读）

1. **横屏视频不要指望 YouTube 自然流量**。想拿算法分发，唯一路径是竖屏 → Shorts 流。
2. **不要把 YouTube 当"发布渠道"，当"仓库 + 嵌入素材"**。冷启动新号的 YouTube 是零分发平台，它的价值在于：被搜索引擎/AI 引用、被嵌进站点和其他平台。
3. **修缩略图 / 章节 / Advanced 权限的收益是"CTR 与转化"，不是"曝光"**。曝光问题得用画幅 + 外部导流解。
4. **播放量数字在冷启动期没有参考价值**。真正该盯的指标是"外部导流回站的 referral 数"。
5. **同一个竖版可以复用到抖音 / 视频号**（若做中文文案）。但中文平台更适合**数据故事**（"13.6% 的中国独立开发者产品已停更"），而不是产品介绍片。
