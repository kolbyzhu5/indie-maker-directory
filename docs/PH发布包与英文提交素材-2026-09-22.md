## 1.2 Tagline · 三选一（全部 ≤60 字符）

| 选项 | 文案 | 字符 | 特点 |
|---|---|---:|---|
| **A（推荐）** | `Discover products built by Chinese indie developers` | **51** | 最直白，把「中国独立开发者」这个差异点放在最前，符合 PH「不要噱头」的要求 |
| B | `A directory of 2,900+ apps, tools and games from China` | **54** | 带规模数字，可信感强，适合想让数字自己说话 |
| C | `Find tools, games and apps made by Chinese indie makers` | **55** | 以动作开头，feed 里扫读友好 |

**我的建议用 A。** 理由：PH 明确要求 tagline「描述产品做什么，不是它有多革命」。A 把最独特的信息（中国 + 独立开发者）压进了前 5 个词，而这是英文目录圈里几乎没人覆盖的角落 —— 差异化本身就是卖点。B 的数字很好，但「2,900+」在 feed 里不如「Chinese indie developers」有信息量。

## 1.3 Description（498 字符，可直接粘贴）

```
AI Indie Maker collects 2,900+ products built by independent developers in China — AI tools, indie games, browser extensions, dev utilities and productivity apps — into one browsable, searchable directory across 12 categories.

The catalog syncs daily from an open-source GitHub list, so it grows without manual curation. Every listing shows the maker, their city when public, and whether the product is still actively maintained.
```

**为什么这样写**：第一段说清「是什么」，第二段说清「为什么它能持续更新」（这是差异点，也是 PH 社区最会追问的地方），第三段把商业模式前置回答掉 —— 目录站评论区第一条永远是「你怎么赚钱」。

## 1.4 图片资产（清单 + 每张的构图）

> **最重要的一条规则**：绝大多数人**只看 feed 里的第一张图，2 秒内决定点不点**。第一张图比整段描述重要。

| # | 用途 | 构图要求 |
|---|---|---|
| 缩略图 | 必需，240×240 | 站内现有标识放大即可；**不要塞入任何小于 40px 的文字**，240px 下必然糊 |
| 1 | **feed 首图（决定生死）** | 首页产品网格实拍 + 一行大字号覆盖文案「**2,900+ products by Chinese indie developers**」。字要大到在 feed 缩略尺寸下仍可读（在 1270 宽画布上字号 ≥ 60px） |
| 2 | 核心动作 | 搜索框输入 `watermark` 后结果收窄的对比截图 —— 一眼看出「这是个能用的目录，不是静态列表」 |
| 3 | 详情页 | 展示作品信息结构：开发者名、城市、状态徽标、外链按钮 |
| 4 | 榜单页 | `/best-ai-tools.html`，说明「有编辑结构，不只是数据库」 |
| 5 | 数据 / 英文版 | `/en/` 英文首页截图，直接回应「有没有英文」这个必然会来的问题 |

**规格**：1270×760 PNG，全部 < 3MB。**首图必须保证在 feed 里不点开也能看懂。**

**Demo 视频（建议做，但要真做）**：30–60 秒纯屏幕录制，一条动线：搜索关键词 → 点进详情页 → 点「访问官网」跳出。**不要配乐、不要片头**，加 3–4 句屏上英文说明即可。YouTube 上传后把完整链接贴进 gallery —— PH 只吃 YouTube，缩短链接不加载。
> 数据参考：2021 年以来拿到 Product of the Day 的产品中约 53% 带视频。视频的作用不是「好看」，是在一个纯静态扫描的信息流里制造运动，并**证明产品真的能用**。

## 1.6 首条自我评论（PH 上最被低估的资产 · 295 词）

> 官方与第三方数据都指向同一结论：**首条评论的阅读量约是产品描述的 10 倍**。
> 发布瞬间（PT 00:01 / 北京 15:01）立刻贴上，**不要等**。不要写「Hey PH, we built X!」，要讲**为什么做、为谁做、哪里还不行**。

```
Hi Product Hunt 👋

I'm Kolby, based in Changsha, China. I built AI Indie Maker because there's a lot of interesting indie work happening in China that almost never shows up in English-language directories — not because it's bad, but because nobody translates it.

There's an open-source list called chinese-independent-developer that a maintainer has curated for years. It's a single Markdown file with thousands of entries. Excellent as a data source, useless as something to actually browse.

So I built the browsable layer on top of it: 2,900+ products across 12 categories — AI tools, indie games, browser extensions, dev utilities, productivity apps — with search, filters, and a maker/status view. The catalog syncs daily from the upstream list, so it grows on its own.

Three things this crowd might find interesting:

1. No paid placement. Nobody can buy a higher position. Getting listed means opening a PR against the open-source list.
2. Every product page shows whether it's still actively maintained — 405 of the 2,963 entries are no longer updated. A directory full of dead links is worse than no directory.
3. 41% of the site's visitors are from outside mainland China, which genuinely surprised me. The English side matters more than I assumed.

The honest limitation: detail pages are still in Chinese. I've translated the homepage and the main lists, but the product pages aren't translated yet. That's a data problem rather than a UI one — the upstream list has no English fields.

One question I'd actually like input on: for a directory like this, what would make you come back a second time? Better filtering, editorial picks, an "alternatives to X" view, or a weekly digest? I have my own opinion but I'd rather hear yours.

Thanks for reading — happy to answer anything.
```

**这段为什么这么写（五个设计点，缺一个效果就掉）**

1. **第二段讲「上游是什么」**——没有人知道中国的开源清单长什么样，「几千行的 Markdown 文件」这个画面本身就解释了产品为什么存在。
2. **第 2 条主动交代 405 个失效作品**——主动暴露弱点反而建立可信度，而且把「状态标识」这个功能变成卖点。
3. **第 3 条用了真实数据（41%）**——具体数字比形容词有说服力，也自然引出了「英文版」这个话题。
4. **诚实承认局限（详情页没英文）**——PH 社区对「藏缺点」极其敏感，先说破，后面的质疑就消失了。而且我给了归因（上游无英文字段），说明这是数据问题不是能力问题。
5. **结尾问一个真问题**——邀请讨论比邀请投票有效得多，且提问是合规的（请求投票才是违规）。

⚠️ **发之前请你自己过一遍这段**，特别是「based in Changsha」和「I built」的主体表述 —— 这是你的署名评论，措辞应该是你本人认可的。

## 1.7 发布当天时间表（北京时间）

> PH 的排行榜在**太平洋时间 00:01 重置**（= 北京时间 15:01），一天一个榜，错过了就等下一个 24 小时窗口。

| 15:10–17:00 | 00:10–02:00 | **私聊**最亲近的 20–30 人：只说「我们上线了，来看看，给点真实反馈」。**不要说「帮我投票」** |

**⚠️ 必须提前知道的两件事（这是我不能替你解决的）**

1. **峰值在美西白天 = 北京时间凌晨 23:00–03:00。** 这是中国区创作者的天然劣势，无法绕开。**如果 15:01 发布后就睡觉，等于放弃了全天的核心时段。** 现实做法：发布当天至少撑到 01:00，次日 07:00 起来补。
2. **PH 数据：发起人 15 分钟内回复评论，获得的后续互动约为 1 小时以上才回的 3 倍。** 回复速度是可见的排名信号。**这一天是全天工作，不是「发一下就完事」。**

## 1.9 红线（触碰可能直接下架）

| 行为 | 后果 |
|---|---|
| **请求投票**（「帮我点个赞」「求 upvote」） | PH 明确禁止。原话：可能「触发算法把产品降权，或从首页移除」 |
| **加入互赞群 / 买票 / 用新号集中投票** | 平台有检测。**新注册账号同时投票是典型机器人特征** |
| **同一产品 6 个月内重复发布** | 不允许 |
| **周一 / 周五 / 周末发布** | 不是违规，但流量明显更差 |
| 发布后不管评论区 | 不违规，但等于浪费掉唯一一次发布机会 |

**可以做的**：把链接发到允许自我推广的社群、请朋友真的来试用并留真实评论、分享你的排名进展（**分享**可以，**索票**不行）。

```
AI Indie Maker (indiemaker.cn) is a browsable, searchable directory of products built by independent developers in China. It covers AI tools, indie games, browser extensions, developer utilities, document and productivity apps, media and audio-video tools, and more — 2,900+ products organized across 12 categories, with search, category filters, status filters, and per-maker and per-city views.

Why it exists: the underlying catalog comes from the open-source chinese-independent-developer list, which a maintainer has curated for years. Pricing and ranking: free to browse, free to be listed. There is no membership tier, no sponsored placement and no paid ranking — position is never for sale. Products enter the directory by being added to the open-source upstream list, which anyone can contribute to via a pull request.

Language: the interface and the main browse pages are available in English and Chinese. Product detail pages are currently generated from the upstream data, which is primarily Chinese, so most detail pages are in Chinese.

Scale today: 2,900+ products, 12 categories, 2,900+ individual product pages, plus themed lists (best AI tools, best indie games, best free tools, best developer tools, best browser extensions, best productivity tools), a local-first section, and a weekly digest.
```
