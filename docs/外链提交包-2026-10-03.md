## 二、提交前必须先定的一件事：用哪个 URL

我们站点同时有中文版 `/` 和英文版 `/en/`。**它们共用同一张分享图是不行的** —— 已核实：`og.png` 是纯中文，英文目录站抓到的卡片会是一张老外看不懂的图。

**规则：**

| 提交到 | URL 用 | 分享图 |
|---|---|---|
| 英文站（Uneed / DevHunt / FutureTools / TopAI.tools） | `https://indiemaker.cn/en/` | `og-en.png`（**已生成**） |
| 中文站（AIBase） | `https://indiemaker.cn/` | `og.png`（现有中文图，正确） |

已核实的依据：`/en/` 页面自带的 OG 就是干净的英文，且数字是最新的 ——

> A directory of AI tools, websites, apps and games created by Chinese indie developers. **3,034 products**, updated daily from an open-source repository. No membership, no paid ranking, entirely free.

（顺带发现：中文首页 description 里写的是过期的「2900+」，实际已 3,034。不影响发外链，记在待修项里。）

**为什么敢把外链指向 `/en/` 而不是首页**：站点的 hreflang 是中英双向声明的，Google 会把 `/` 与 `/en/` 当成同一实体的两个语言版本，权重在站点层面归并 —— 不存在"权重被分走"的问题。而 `/en/` 恰恰是当前内链最薄、最缺外部权重的那一页（首页只引 `/c/` 12 条、`/p/` 0 条），外链给它正好补短板。加上英文用户点进来能读懂，这件事没有反方向风险。

**英文分享图已做好**：`og-en.png`（1200×630，与中文版同款版式、同套配色 #b3292e / #f5f0e6）。源文件 `docs/assets/og-en.svg`。
✅ **已上线**（2026-10-03，CI run `37112176019` 全绿）：`en-pages.mjs` 的 og:image 已指向 `/og-en.png`，文件已加入 `build.mjs` 的 dist 同步列表，`copyFile` 的静默跳过改为显式 warn。线上实测 `og-en.png` **200 / 42,915B / 1200×630**、md5 与本地逐字节一致；英文页 **11/11** 指向新图、中文页 12 张仍为 `og.png`（零误伤）。
⚠️ 若某目录站抓到的仍是中文图，那是**它自己侧的图缓存**，在站内编辑页手动替换即可，与本仓库无关。

## 三、Uneed 逐步操作（5 分钟）

**入口**：https://www.uneed.best/submit-a-tool 　实测 **200 可用**

1. 打开入口页。页面明确写着：**"No account needed to start — we'll scrape your page first, then ask you to sign up to save it."**
2. 第一个框 **Your product name** 填：
   ```
   AI Indie Maker
   ```
3. 第二个框 **Your product address** 填：
   ```
   https://indiemaker.cn/en/
   ```
4. 点 **Submit your product** → 它的机器人会自动抓取你站点的数据（这一步不需要账号）。
   ⚠️ 按钮实测文案是 `Submit your product`。早期资料多写作 `Preview my product`，以页面实际为准 —— 别因为找不到 Preview 按钮以为走错了页。
   💡 填完名称后，输入框下方会自动生成条目 slug 预览（如 `https://www.uneed.best/tool/ai-indie-maker`）。**若它没提示"已被占用"，说明这个名字还没人提交过**，是干净的首次提交。
5. 抓完后会让你**注册账号**才能保存。注册方式实测（`/login` 页原文：*Don't have an account? [Sign up]*）：
   - **Google 一键登录** ← 最快，不用记密码
   - **Email + Password**（有 `Forgot password` 通道）
6. ⚠️ **不要点任何付费选项**（这类站通常有 "skip the queue / featured" 付费加速）。免费提交即可。

**抓取之后要手工核对/覆盖的字段**（机器人抓的常不准，以你填的为准）：

| 字段 | 填什么 |
|---|---|
| Name | `AI Indie Maker` |
| Tagline（≤60 字符） | `Free directory of 3,000+ Chinese indie developer products` |
| Category | `Directory`（备选 `AI Tools` / `Developer Tools`） |
| Pricing | `Free` |
| Tags | `ai-tools, directory, indie-hackers, side-projects, china, curated-list` |
| Logo | `favicon.svg` 或 `og-en.png` |
| Screenshots | 站点首页截图（手机端优先，近 7 天移动端占 34%） |

**长描述（英文，可直接粘贴）**：
```
AI Indie Maker is a searchable directory of 3,000+ products built by Chinese independent developers — AI tools, web apps, browser extensions, indie games and productivity software. The catalog is synced daily from an open-source GitHub list, so it keeps growing without manual curation. Everything is free to browse: no membership, no paid ranking, no sponsored placements.
```
