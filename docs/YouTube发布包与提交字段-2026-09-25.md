## 2. 中英双版的正确处理方式

优先顺序（从好到差）：

1. **多语言音轨**（若频道已具备资格）：同一支视频上传英文字幕轨 + 中文音轨/字幕轨，一支视频吃两个受众。
   YouTube Studio → 视频 → 「字幕」→ 添加语言。这是最优解，不分散播放量。
2. **两支独立视频**：英文版公开，中文版也公开，但**标题/说明全部用中文**，并在两支的置顶评论里互相链接。
   风险是播放量被拆成两半，各自都不到推荐门槛。
3. **中文版设为「不公开列出」**：只用于置顶评论或社区帖里给中文用户看。播不动但不干扰主视频数据。

**建议**：先只发英文版 `01-video-EN`，观察 7 天。中文版按第 3 种方式挂着，等主视频跑出数据再说。

- 你的受众 **41% 在海外**（CN 143 / 非 CN 101，HK 42 + US 36 为主）。YouTube 的推荐峰值在**美西白天**。

- ⚠️ 上一条同样适用于 Product Hunt：**发布当天是全天工作**，不是你点完按钮就结束。前 30 分钟内回评论带来的后续互动量，
  显著高于隔几小时再回。

## 4. 红线与合规

### 4.1 绝对不要做
- **不要买播放、不要进互赞/互订阅群**。YouTube 对「非真实互动」的判定是账号级的，会连带影响后续所有视频。
- **不要在标题/说明里堆关键词**（例如把「ai tools ai directory best ai tools」重复三遍）。会被判 spam。
- **不要上传未经授权背景音乐**。本片没有音乐，只有配音 —— 这是**故意**的，零版权风险。
- 封面文字不要超过全图 30%，否则移动端会被 UI 遮挡（本片封面已按此设计）。

### 4.2 关于背景音乐
现在没有配乐。若之后想加，用 **YouTube 音频库**（Studio → 音频库，筛选「无需署名」）下载，再用：
```
ffmpeg -i video-en.mp4 -i music.mp3 -filter_complex "[1:a]volume=0.12,aloop=loop=-1:size=2e9[m];[0:a][m]amix=inputs=2:duration=first:dropout_transition=0[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k video-en-music.mp4
```
音量压到 12%，配音必须始终清楚。**别用**平台外的「免费音乐」站点，版权溯源是最大的隐形风险。

### 4.3 关于「修改内容披露」开关
- 本片合成的是**通用 TTS 配音**，画面是真实站点录屏，**没有生成任何真人形象或真实事件**。
- YouTube 的强制披露红线针对的是「会被误认为真人/真实事件的合成内容」。因此本片**不需要**打开该开关，
  但仍已在说明里主动写明配音为 AI 合成 —— 这是诚实且安全的做法。
- 若平台后续提示或误判，再打开开关即可，不会有惩罚。

本片 76 秒，是 16:9 横版，**不会进入 Shorts 流量池**。Shorts 需要 9:16 竖版。

## 5. 验收指标（别用播放量当标准）

| 时间点 | 看什么 | 判定 |
|---|---|---|
| 发布 48h | 曝光点击率（CTR） | <4% = 封面/标题有问题，换封面重测 |
| 发布 7d | 平均观看时长 / 观看比例 | 76s 片长，平均时长 <30s = 前 10 秒没抓住人 |
| 发布 7d | 流量来源里 organic search 占比 | 这是**唯一和 indiemaker.cn 收录量直接相关**的指标 |
| 发布 30d | 简介里 5 个链接的点击（看 Umami 的 referral） | 决定后续视频是否继续做 |

YouTube 是渠道之一，不是终点。**站点的最终验收仍看 Organic Search 访客数是否持续上升。**
