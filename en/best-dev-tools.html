Frequently asked questions

What developer tools are on this list?

AI coding and agent platforms, model API gateways and routers, research and visibility tooling, security and forensics utilities, plus plugins and resources that speed up day-to-day development.

Are these tools open source?

Many are. Where a project is open source the product page links to its repository. Others are free-to-use hosted services, sometimes with a paid tier for heavier usage.

Can I self-host any of these?

Several are designed to be self-hosted — particularly API gateways and agent frameworks. Check the individual product page for deployment details.

Do these tools send my code or data to a third party?

It varies, and it matters. Tools that route your traffic through their own servers necessarily see that traffic. We flag tools that run locally or let you plug in your own model keys, but always verify before pointing them at private code.

How do I get my own tool listed?

Submit a pull request to the upstream open-source repository, chinese-independent-developer. The directory syncs from it daily.
