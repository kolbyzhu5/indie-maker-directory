常见问题

有哪些不上传文件的在线工具？

AI 独立制造所从 2900+ 个中国独立开发者作品中筛选出 167 个「文件不上传服务器」的工具，覆盖图片处理（抠图、去水印、图片压缩）、PDF 与文档处理、音视频转写、开发调试等场景。这些工具的运算在浏览器内完成，文件全程留在你的设备上。

怎么判断一个在线工具会不会上传我的文件？

三个可验证的方法：① 看它是否明确声明「本地处理 / 不上传 / 浏览器内运行」；② 断网后再打开工具，若核心功能仍可用，说明运算在本地；③ 打开浏览器开发者工具的 Network 面板，处理文件时观察是否有大体积的对外请求。

处理身份证、合同、病例这类敏感文件，用什么工具安全？

优先选择声明「浏览器本地处理」的工具。本榜单优先收录这类产品——例如证件照制作、PDF 对比、图片去水印等均有本地处理方案，文件不会上传到任何服务器，从机制上排除了第三方留存的风险。

浏览器本地处理是怎么实现的？

主流做法有两种：一是用 WebAssembly 把原本需要服务端的算法（如图像修复、PDF 解析）编译到浏览器里运行；二是直接用浏览器的原生 API（Canvas 处理图像、File System Access API 读写本地文件）。两者的共同点是：文件数据从头到尾没有离开设备。
